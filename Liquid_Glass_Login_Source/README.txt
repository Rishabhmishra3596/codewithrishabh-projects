Liquid Glass Login — Code With Rishabh
Open index.html with all files and assets together. Both fields start empty. Enter a valid email and an 8+ character password, then Log in. Try again resets. The eye icon toggles password visibility.
This is a front-end animation demo, not real authentication. No credentials are sent or stored.
The highly reflective glass and background are generated raster assets in assets/. HTML inputs, button, cursor, loading and success interactions are implemented with CSS and JavaScript. Keep the assets when sharing the source.
source-preview.js shows exact source excerpts in the three code panes.
The reel runs 18 seconds (1080x1920, 30fps), with two nine-second demonstrations: blank fields, email typing, password typing, click, loading, success.
The Gmail address shown is demo text only.
