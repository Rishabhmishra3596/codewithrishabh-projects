Sneaker Studio — @codewithrishabh3596

Open index.html in a modern browser. No dependencies or installation required.
The 18-second demo automatically loops. Click a colour swatch to enter interactive
mode. Explore toggles the feature cards. Reload to restart the automatic demo.

The MP4 is silent, 1080 x 1920, 30 fps, 18 seconds. Add music when posting.
Animated sequence: angled spin-and-bounce entrance, hovering, visible cursor
clicks at 4/8/12 seconds changing coral/charcoal/blue, ripple after each click,
Explore click at 14.2 seconds and feature cards revealing afterwards.

The shoe is a realistic 2D product sprite with animated rotation, scale and
position. It is not a navigable 3D mesh or a full 360-degree product viewer.
Product feature labels are illustrative demo text, not verified specifications.
HTML, CSS and JavaScript excerpts scroll in the three editor panels. Complete
source is included in this folder.
